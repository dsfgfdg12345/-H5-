企业内部培训、职业资格备考、驾考理论学习、网校线上刷题，这类场景的共性需求是：稳定的题库管理、灵活组卷、模拟考试、错题复盘、成绩统计，同时支持学员随时随地移动端学习。这套在线考试题库答题刷题 H5 小程序源码，覆盖**题库管理、刷题练习、模拟考试、章节练习、错题本、学习记录、学员管理、成绩报表**全链路，支持 H5、微信小程序多端访问，是一套通用型线上教育考核底座，可面向驾考、企业内训、职业考证、技能培训、网校等场景快速落地。

## 技术与架构特点

后端常用 FastAdmin/ThinkPHP 生态（同系列源码常见技术栈），前端采用 Uniapp 开发，一套代码同时编译微信小程序、H5，无需单独开发多端。后台管理端负责题库、试卷、学员、配置的统一管理；学员端以小程序 / H5 作为学习入口，做到管理员和学员权限隔离。源码可私有化部署，支持二次开发，适合服务商承接企业培训项目、搭建垂直刷题网校、驾考学习平台。

## 核心业务模块拆解

### 1. 题库管理（底层核心）

支持多种题型录入：单选题、多选题、判断题、简答题、不定项选择题。支持**单题录入、Excel 批量导入题库**，大幅降低大批量题库上架成本。题目可绑定分类、章节、知识点、难度标签，支持上传题干配图、选项配图，适配驾考看图题、职业技能识图题。
支持题目解析、答案解析、考点备注，学员答题后可查看解析；同时支持题目启用 / 禁用，方便临时下架过时考题。

### 2. 多种刷题模式，适配不同学习阶段

- **章节练习**：按教材 / 知识点章节拆分题库，定向刷对应板块题目，适合循序渐进学习；
- **顺序刷题**：按题库顺序逐题练习；
- **随机刷题**：随机抽取题目，打散顺序，强化记忆；
- **错题本**：自动收集答错题目，支持反复重做错题，是备考场景高频功能；
- **收藏题目**：学员标记重点题，单独形成收藏题库；
- **我的练习记录**：记录每一次练习进度、答题记录，支持断点续做。

### 3. 模拟考试 & 正式考试

支持管理员手动组卷、智能随机组卷两种模式。可设置试卷名称、考试时长、及格分数、题目数量、是否打乱选项顺序、是否允许查看答案解析。
支持两种考试模式：

- 模拟考试：交卷后立刻出分、查看错题解析；
- 正式考核：企业培训场景常用，可设置考试防切屏、限时、多次考试限制、重考间隔，适合员工考核、上岗测评。
交卷自动判分，生成成绩单，记录考试用时、正确率、错题明细。

### 4. 学员管理与权限体系

后台支持学员手动添加、批量导入、注册开放；学员可手机号注册、验证码登录。支持学员分组、标签管理，企业场景可以按部门、岗位分组，定向分配试卷。
配套 RBAC 权限，区分超级管理员、题库管理员、阅卷管理员、统计查看员；简答题等主观题支持后台人工阅卷打分，弥补 AI 自动判分局限。

### 5. 学习数据、统计图表与报表

后台数据看板可视化展示：学员总数、考试次数、通过率、平均分、错题排行、热门试卷。支持按学员、试卷、时间段筛选成绩，导出 Excel 成绩单，方便企业 HR、培训负责人做培训考核归档。
支持查看单学员学习档案：练习时长、考试记录、薄弱知识点，定位学习短板。

### 6. 配套网校增值能力（可选扩展）

很多版本附带课程模块：图文课程、视频课程、课程打包、付费购买、会员套餐，从单纯刷题题库升级为网校系统。可搭配付费题库、付费试卷、VIP 解锁全部题库，实现商业变现；驾考场景可单独配置科目一、科目四专属题库包。

### 7. 适配场景差异化配置

- 驾考：图片题优先、全真模拟卷、无限次刷题、精简解析；
- 企业培训：部门分组、强制考试、培训签到、考核留档、防作弊配置；
- 职业考证：章节划分、考点标签、历年真题卷、专项刷题；
- 网校教育：课程 + 题库联动，学完课程后自动推送对应测试卷。

## 落地优势与边界

对比 SaaS 考试平台，这套源码最大优势是**私有化部署、数据自主掌控、可深度定制**。服务商可以基于这套底座，快速给不同行业客户交付刷题系统，不用从零开发题库、答题逻辑、成绩统计。
同时也要看清边界：它主打标准化线上答题刷题，适合理论类考核；复杂实操类考核、高严谨性国家级统考场景不适用。作弊管控能力以轻量防切屏为主，高保密考试场景需要叠加额外风控方案。
